# Rocket Physics Simulators
A collection of first-principles physics and trajectory simulation tools built entirely on an Android tablet.

## Current Milestone
- **1D Python Simulation:** Complete. Safely tracks thrust vs. gravity, mass drop from fuel burn, and suborbital atmospheric entry (successfully crossed the Kármán line at 100km).
- **Next Project:** Integrating 2D vector trigonometry to simulate rocket steering and pitch-over maneuvers.
